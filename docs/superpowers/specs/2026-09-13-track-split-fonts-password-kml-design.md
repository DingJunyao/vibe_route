# 轨迹拆分、字体管理、改密与 KML 兼容设计

日期：2026-09-13

## 目标

本轮在现有轨迹、道路标志字体和认证流程上增加五项能力：

1. 在轨迹详情页把一条轨迹按点区间拆分为多条新轨迹，原轨迹保持不变。
2. 把印尼 Clearview 上下两组字体纳入管理员字体管理。
3. 修复印尼路牌字体切换后仍可能读取旧 SVG 缓存、看起来字距未更新的问题。
4. 用户在设置页通过旧密码自助修改密码。
5. KML 导出可选择路径或轨迹形式，并明确网页版 Google Earth 的兼容性。

## 轨迹拆分

### 接口

新增 `POST /api/tracks/{track_id}/split`。请求体包含一个或多个区段：

```json
{
  segments: [
    {start_index: 0, end_index: 120, name: 可选名称, description: 可选备注}
  ]
}
```

`start_index`、`end_index` 都是原轨迹当前有序点数组中的闭区间下标。后端校验：

- 轨迹属于当前用户且不是正在进行的实时记录。
- 区段按端点顺序递增且互不重叠。
- 下标合法、每段至少两个点。
- 所选点存在且都属于原轨迹。

### 复制语义

每个区段创建一条新轨迹。统计值、起止时间和是否有行政区划/道路信息根据复制点重新计算。新点 `point_index` 从零重排；坐标、时间、海拔、速度、方位、行政区划、道路、多语言、region、memo、`is_interpolated` 原样继承；`interpolation_id` 置空，避免关联到原轨迹的插值记录。原轨迹及其点不修改。

### 前端交互

轨迹详情页桌面工具栏和移动端入口增加“拆分轨迹”。拆分使用不遮挡地图的右侧抽屉，地图按区段着色并显示切点标记；用户可直接点击地图轨迹，二次确认后按最近轨迹点添加切点，也可在有序点列表中手工勾选。抽屉展示索引、时间、坐标、海拔、速度和道路信息，并允许逐段勾选、改名。提交选中的区段，成功提示中给出新轨迹数量。

## 印尼字体管理

复用现有字体上传、删除、列表和激活接口，激活类型增加 `id_upper` 与 `id_lower`。后端分别写入 `indonesia_road_sign.font_upper` 和 `font_lower`，文件仍存储在共享字体目录。管理页按中国 A/B/C 与印尼两组展示，完善状态提示。

删除字体时同时清理中国和印尼配置中的引用。道路标志缓存键加入实际字体文件名、模板名及排版版本，字体或模板变化后自动生成新的 SVG。

## 自助修改密码

新增需登录的 `POST /api/auth/change-password`，请求包含 `old_password` 与 `new_password`。前端沿用现有 SHA-256 后传输的链路；后端用 bcrypt 校验旧密码并保存新密码。错误旧密码返回 400，新密码复用现有最小长度约束。设置页用户信息区域增加旧密码、新密码和确认密码表单。

## KML 导出

`GET /api/tracks/{track_id}/export` 的 KML 请求增加 `kml_type=track|path`，默认 `track` 以兼容旧客户端：

- `track`：输出 `gx:Track`，保留逐点时间，适用于两步路等支持轨迹扩展的应用。
- `path`：输出标准 `Placemark -> LineString -> coordinates`，兼容网页版 Google Earth，保留坐标和海拔但不保留逐点时间。

前端在 KML 导出对话框内用单选组提供形式选择与兼容性说明，路径形式默认选中，并在文件名中加 `_path` 后缀。轨迹形式文件名保持现有规则。

## 验证

- 拆分：字段继承、原轨迹不变、多区段、索引重排、非法/重叠区段。
- 字体：印尼上下字体可激活并写入配置；删除时清理引用；字体或模板变化导致缓存键变化。
- 改密：旧密码错误、成功后新密码可登录、会话令牌行为不变。
- KML：默认轨迹格式结构不变；路径格式不含 `gx:Track`，坐标顺序为经度、纬度、海拔。
- 前端执行类型检查或构建；后端运行聚焦测试。
