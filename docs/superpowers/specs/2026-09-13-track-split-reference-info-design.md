# 轨迹拆分参考信息重设计

日期：2026-09-13

## 背景与目标

轨迹拆分页（`frontend/src/views/TrackSplit.vue`）当前的"划分规则"面板提供自动/手动开关：开启后按所选维度（省/州、市/县、区、道路编号、道路名称）的属性变化直接生成切分边界，并按"最短区段点数"合并短区段。实际使用中并不需要按行政区划或道路自动切分，这些信息只应作为拆分时的参考。

本轮重设计目标：

1. 区段完全由手动切点决定，移除自动切分及其合并逻辑。
2. 行政区划、道路信息改为聚合展示，供设切点时参考。
3. 参考信息与切点操作联动：可定位到地图，可一键在变化点设切点。
4. 恢复地图轨迹点悬停气泡，与轨迹详情页一致。

## 交互模型

- 切分只由手动切点决定；维度选择从"切分规则"变为"参考视角"。
- 选择一个维度后，系统展示轨迹在该维度上的聚合信息：哪些值、每次连续出现的点区间、点数、距离。
- 用户参考聚合信息手动设切点（点击地图、或从参考条目一键设切点）。

## 参考信息面板（替换"划分规则"面板）

- 维度选择器保留五种：省/州、市/县、区、道路编号、道路名称。
- 聚合列表按维度值聚合，按首次出现顺序排序。每个条目展示：
  - 名称（如"江苏省"、"G2"）
  - 汇总：出现次数 · 总点数 · 总距离
  - 展开后每次连续出现一行：`#起–#止 · 点数 · 距离`
- 出现区间的行可点击定位（地图缩放到该区间）。
- 区间起点不为 0 时，行内提供"在此设切点"按钮；点击即在区间起点添加手动切点；该点已是切点时按钮呈已生效状态。
- 保留搜索框，过滤参考条目（按名称匹配）。
- 删除"自动/手动"开关与"最短区段点数"参数。GPS 抖动产生的短闪烁在列表中天然可见（很短的区间行），不做过滤。

## 区段预览面板

- 不再按维度分组，改为按序号平铺的区段列表。
- 卡片保留：序号、点区间、点数、距离、时间范围、命名输入、勾选（上限 100 保留）。
- 每张卡片新增一行摘要：该区段在当前维度下途经的值（如 `江苏省 → 安徽省`），跨多个值时逐个列出。
- "并入上一区段"按钮保留，语义为移除该区段起点处的切点。

## 地图

- 移除 `:disable-point-hover="true"`，悬停轨迹点显示气泡（时间、坐标、行政区划、道路、路牌等），与轨迹详情页一致。
- 新增"标记变化点"开关，默认开启：当前维度发生变化的点以小标记在图上标出，样式区别于橙色切点圆点。
- 切点吸附最近原始点、图例、点击加切点逻辑不变。

## 当前切点面板

保留现状。"自动边界"状态随自动边界机制移除，状态只剩"手动切点"/"未设切点"。

## 代码改动

### `frontend/src/utils/trackSplitSegments.ts`

- 删除 `mergeShortSegments`。
- `buildContiguousSegments` 保留，用途改为计算参考信息中的连续出现区间（runs）。
- `refineSegmentsWithCuts` 简化：仅由切点生成区段，不再叠加自动边界。
- 新增聚合函数：按维度值聚合出现区间（名称、次数、点数、距离、区间列表）；计算给定区段途经的维度值摘要（去重、按出现顺序）。

### `frontend/src/views/TrackSplit.vue`

- 删除状态：`autoGroup`、`minimumSegmentPoints`、`disabledAutoBoundaries` 及对应 watcher。
- "划分规则"面板重构为"参考信息"面板（维度选择、聚合列表、搜索、设切点按钮、变化点开关）。
- "区段预览"去分组平铺，卡片增加途经值摘要行。
- 移除 `disable-point-hover`。

### 后端

无改动，`POST /api/tracks/{track_id}/split` 接口语义不变。

## 边界情况

- 维度数据全为空：聚合列表显示单一"未识别"条目。
- 变化点恰为起点（index 0）或终点：不提供设切点（与现有切点合法性规则一致）。
- 移动端（≤1366px 断点）：沿用现有纵向堆叠布局，参考列表与区段列表各自可滚动。

## 验证

- 前端 `npm run build` 通过，无类型错误。
- 浏览器中验证：多引擎（高德/百度/腾讯/Leaflet）下气泡、变化点标记、切点交互正常；聚合统计与实际点数据一致。
